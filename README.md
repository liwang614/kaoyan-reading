# 考研英语阅读 · 生词难句标注

在浏览器里阅读考研英语阅读真题，用鼠标选中生词和难句做标记，再导出成 Markdown。

## 克隆后双击即可使用

1. 克隆仓库（也可以下载 ZIP 后解压）。
2. 双击根目录的 **`打开即用.html`**，用 Chrome、Edge、Firefox 或 Safari 打开。
3. 开始阅读、标注和记录错题。

不需要安装 Python、Node.js、Docker，不需要输入命令，也不需要联网或注册云平台。68 篇阅读原文和 2010—2026 年的词频资料已经放在这个文件里；单独复制此 HTML 给别人也可以使用。Windows 和 macOS 均使用同一个 HTML 文件。

标注、进度和做题记录自动保存在当前浏览器中，每个人的数据独立。工具栏的“备份数据”可导出完整 JSON，“恢复数据”可在另一台电脑或浏览器中导入。更换浏览器、移动或重命名 HTML、清除浏览器数据之前请先备份；建议固定文件位置，并使用普通浏览窗口。

本地文件存储规则由浏览器决定；如果浏览器限制本地文件存储，请换一个允许存储的常规浏览器。双击版不会读取原 Python 服务 `data/` 中的记录，也不会改动它们。

## 命令行克隆与更新

已安装 Git 的用户，可以在终端执行以下命令克隆仓库：

```bash
git clone https://github.com/liwang614/kaoyan-reading.git
cd kaoyan-reading
```

然后双击文件夹里的 `打开即用.html`，也可以用命令直接打开：

macOS：

```bash
open "打开即用.html"
```

Windows（PowerShell）：

```powershell
Start-Process ".\打开即用.html"
```

以后更新，在 `kaoyan-reading` 文件夹内执行：

```bash
git pull --ff-only
```

更新后重新打开或刷新 `打开即用.html`。保持文件位置和使用的浏览器不变，原有学习记录仍保存在浏览器中；更新前也可以点击“备份数据”留一份备份。

仓库目前为私有，需要先获得访问权限，并使用有权限的 GitHub 账号完成 Git 身份验证。没有安装 Git 也可以使用仓库页面的 **Code → Download ZIP**，解压后双击同一 HTML 文件。

## 可选：原 Python 服务版

已经安装 Python 3 的 Mac 也可以双击 `start.command`；或运行 `python3 server.py`，浏览器会自动打开 `http://127.0.0.1:8765`。此模式仍使用项目目录中的 `data/` 保存记录，与 HTML 双击版的数据独立。

需要部署到服务器时，再看 [可选部署说明](DEPLOYMENT.md)。

## 使用

1. **首页**：按年份正序（2010 → 2026）列出 Text 1–4，点进要读的那篇；阅读页的「上一篇 / 下一篇」也按这个顺序走。每篇有三种进度状态：
   - **未做**：还没有标注（白色卡片）。
   - **进行中**：标了第一个词或句子后自动变成进行中（琥珀色）。
   - **已完成**：在阅读页顶部点「✓ 已完成」（绿色）。阅读页顶部也可以随时手动改回未做或进行中。
   - 顶部有总进度条和「全部 / 未做 / 进行中 / 已完成」筛选，「继续上次」直接回到最近打开的那篇；年份下的小圆点是这一年四篇的进度。
2. **阅读页**：用鼠标选中单词或句子，在弹出的菜单里点「生词」或「难句」（快捷键 `D` / `F`）。
   - 标生词时会自动补全成完整单词，并去掉两端的标点。
   - 点击已经标过的内容可以删除；右侧列表点击可定位，点 ✕ 删除。
   - 右侧「生词」「难句」面板点标题可以折叠；点「收起」把整个侧栏收到右边缘，正文变宽，点右侧把手再展开。折叠状态会记住。
   - 每次改动都会自动保存；HTML 双击版保存到浏览器，Python 服务版保存到 `data/marks/`。
   - 每个生词后面显示「历年 N」：它在 2010–2026 全部真题文本（阅读原文、阅读题目、完形、新题型、翻译、写作）里出现的次数，点开看每年出现在哪部分、有哪些词形。
     - 按原形合并统计（contend / contends / contended 算同一个词，短语也认变形）。以 -ing / -ed 结尾的独立名词或形容词（如 parenting、contented）会被并到原形上，所以同时显示「本词形 N 次」供你判断。
3. **导出**：
   - 阅读页的「下载本篇 MD」：只导出当前这篇。
   - 首页点「选择导出」进入选择模式：
     - 点卡片选中 / 取消；点年份整年选中；按住 Shift 点击可连续选一段；底栏还有全选、仅已标注、反选、清空。
     - 导出方式：**每篇一个 md**（多篇打包成 zip）或 **合并为一个 md**（末尾附去重后的生词总表）。
     - 导出内容可多选：生词、难句、做题结果、历年统计（生词表的「历年出现 / 分布」两列，需同时选生词）。阅读页的「下载本篇 MD」也会弹出同样的选项，两处共用并记住选择。
     - 选择会记在浏览器里，下次打开还在。

## 做题记录（原「英语真题记录」，已并入）

顶栏左侧切换「阅读标注 / 做题记录」。

- 记录每年 45 道客观题（完形 1–20、阅读 21–40、新题型 41–45）的对错和错选项，以及用时、做题顺序，可下载 Markdown / JSON（与原项目相同）。
- 键盘：`1` 未做、`2` 对、`3` 错（再输入 A–D / A–G 回车）；方向键切题，`Delete` 清除。
- 和阅读联动：阅读 Text n 对应 21+5(n−1) 起的 5 题。
  - 首页阅读卡片右上角显示「✓ 对几道 / 已做几道」。
  - 导出 md 时可选择带上每篇的「做题结果」。
- HTML 双击版的记录保存在浏览器中，可用“备份数据 / 恢复数据”完整迁移；Python 服务版使用 `data/records.json`。

## 配色

顶栏的圆形色块按钮打开配色面板：16 个预设色调、色相滑块、色彩浓度、背景光晕、明暗（跟随系统 / 浅色 / 深色）。整个界面随色相一起变化，设置保存在浏览器里。

## 修改文章（开发者）

```
articles/
  2015/
    text1.txt
    text2.txt
  2016/
    text1.txt
```

- 纯文本，UTF-8 编码。
- 段落之间空一行；同一段内的换行会自动合并成空格。
- 修改文章、语料或前端代码后，运行 `python3 scripts/build_standalone.py` 重新生成 `打开即用.html`，再提交到 GitHub。生成过程不会读取个人学习记录。

## 目录结构

| 路径 | 内容 |
|------|------|
| `打开即用.html` | 推荐入口，双击即可离线使用 |
| `static/offline.js` | 双击版的浏览器存储和导出实现 |
| `scripts/build_standalone.py` | 更新双击版 HTML（仅开发者需要） |
| `server.py` | 可选的本地服务器（只用 Python 标准库） |
| `static/` | 前端页面 |
| `articles/` | 阅读原文 |
| `data/marks/` | 标注记录（JSON） |
| `data/progress.json` | 每篇的进度状态和最近打开时间 |
| `data/records.json` | 做题记录（对错、错选项、用时、做题顺序） |
| `corpus/` | 历年完形、阅读题目、新题型、翻译、写作的文本，用于统计生词出现次数 |
